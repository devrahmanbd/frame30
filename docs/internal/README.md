# Internal docs (staff only)

This folder holds staff-only review and contract notes. It is not
published to third-party developers. The third-party counterpart is
the [third-party developer index](../developers/README.md).

- [SDK contracts](sdk-contracts.md) — normative integrator
  contracts for server functions, tables, and the registry pipeline;
  readers are staff reviewers and platform engineers.
- [Submission gates runbook](submission-gates.md) — the
  copy-pasteable gate commands, green criteria, human checklist,
  approval steps, kill-switch procedure, and resubmission path that
  a reviewer follows with only that document plus gate output.
- [Theme isolation](theme-isolation.md) — normative
  no-shared-components-in-themes rule (AGENTS.md rule 7): allowed vs
  refused imports, incident history, and the reviewer checklist.

Authoritative code-adjacent references (read-only from this
folder's perspective):

- [Builder runtime guide](../04-builder/README.md) — token
  channel, preview engine, persist shape, and twin parity behavior
  for themes at runtime.
- [Theme authoring reference](../themes/creation.md) — the
  end-to-end authoring reference for tokens, skins, homepage
  builders, stylesheets, preview sources, and the theme test suite.
