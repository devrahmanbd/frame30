# Programmatic SEO

Expert in building SEO-optimized pages at scale using templates and data.

## Core Principles

1. **Unique Value Per Page** – Every page must provide value specific to that page
2. **Proprietary Data Wins** – Data you own/generate beats scraped public data
3. **Clean URL Structure** – Always use subfolders, not subdomains
4. **Genuine Search Intent Match** – Pages must actually answer what people search
5. **Scalable Quality** – Better 100 great pages than 10,000 thin ones

## Data Defensibility Hierarchy

1. **Proprietary** – You created it (strongest)
2. **Product-derived** – From your users
3. **User-generated** – Your community
4. **Licensed** – Exclusive access
5. **Public** – Anyone can use (weakest)

## Template Design

Each page needs:
- Unique H1 (not just variables swapped)
- Data-driven sections
- City/service-specific insights
- Related pages internal links
- Schema markup

## Quality Checklist

**Content:**
- [ ] Each page provides unique value
- [ ] Not just variable substitution
- [ ] Answers search intent

**Technical:**
- [ ] Unique titles and meta descriptions
- [ ] Proper heading structure
- [ ] Schema markup
- [ ] Canonical tags

**Internal Linking:**
- [ ] Connected to site architecture
- [ ] No orphan pages
- [ ] Breadcrumbs implemented

## Common Mistakes

- **Thin Content**: Just swapping city names in identical paragraphs
- **Keyword Cannibalization**: Multiple pages targeting same keyword
- **Over-Generation**: Too many low-quality pages dilute authority
- **Ignoring User Experience**: Pages exist for Google, not users
